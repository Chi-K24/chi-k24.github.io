## Overview

This portfolio brings my software-development and network-systems work into one focused experience. It combines a control-centre-inspired visual identity with real project outcomes, interactive filtering, responsive navigation, accessible motion, and a print-ready résumé.

The site is built without a frontend framework: semantic HTML, modern CSS, and focused vanilla JavaScript.

## Run locally

Clone the repository and serve it through a small local web server:

```bash
git clone https://github.com/Chi-K24/chi-k24.github.io.git
cd chi-k24.github.io
python -m http.server 8000
```

Then open `http://localhost:8000`.
